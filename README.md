
# Nifty50 AI Prediction Project

An AI-powered platform for NIFTY 50 market analysis and price prediction using historical and live market data.

## Project Overview

This project combines Machine Learning and financial market data to analyze NIFTY 50 trends and generate price predictions.

## Live Demo

https://nifty50-ai.vercel.app

## Technologies

- Python
- Machine Learning
- React
- Vercel
- Financial Market Data APIs

## Disclaimer

This project is developed for educational and research purposes only. Predictions are not financial advice.
